# Sitio web y contenido (CMC) dentro del ERP

**Fecha:** 12 de octubre de 2026, America/Mexico_City.

**Motivo:** administrar la página CometaLink desde ComeCore, conservando el CMC
original y sin reanudar el análisis de Facturación e Inventario.

**Resultado:** nuevo módulo `/sitio-web` con contenido, doce paletas, ocho colores,
mensajes de temporada, vista previa, borrador protegido y publicación local real.
La sesión y MFA del ERP protegen página y API. El puente acepta una sola
organización y exclusivamente operaciones de contenido. El sitio público y las
otras funciones del CMC mantienen su integración existente.

## Archivos y datos

| Archivo o grupo | Cambio |
| --- | --- |
| Frontend `src/features/sitio-web` | Adaptación adicional del editor original; CSS delimitado al módulo. |
| Frontend `app/(erp)/sitio-web`, `app/api/cmc/content` | Página protegida y BFF para la conexión de contenido. |
| Frontend `config/modules`, `lib/auth/config` | Entrada de navegación y permiso de ruta. |
| Backend `src/cmc`, `src/main`, `security/runtime` | Conexión fija local, permisos y autorización de cada petición. |
| Proyecto CMC `backend/integrations` | Puente HTTP loopback y contexto interno por objeto Request. |
| Proyecto CMC `backend/netlify/functions/cmc.mjs` | Extensión mínima para identidad interna de contenido, validación estricta y revisión bajo bloqueo; autenticación original conservada. |
| Scripts `setup-cmc-local`, `initialize-cmc-local`, `run-cmc-local` | Configuración privada, importación de contenido público y arranque local. |
| Scripts `test-cmc-integration`, `cleanup-cmc-fixture` | Verificación completa con cuentas temporales y limpieza específica. |

**Migraciones:** no aplica. El contenido conserva el almacén cifrado original del
CMC. No se inventaron tablas ni se alteró el esquema PostgreSQL.

El inicializador copió el documento público leído de `cometalink.net/api/site`
a una copia local cifrada y no publica nada al servidor. Conserva una copia local
ya existente sin sobrescribirla. Los secretos están fuera de Git y no se registran
en esta nota ni en la interfaz.

Se corrigieron durante la integración: incompatibilidad entre revisión numérica
y hash del contrato, inicialización explícita de la copia local y prueba de
redirección relativa. Se retiró un interruptor que habría aparentado activar
mantenimiento desde contenido: su activación pertenece al parámetro operativo
del CMC original.

Las pruebas del módulo no equivalen a certificar la seguridad completa del ERP.
La revisión general de autenticación iniciada anteriormente sigue pendiente.

Selecciona una tabla

Verás sus columnas y relaciones reales. El diagrama contiene solo estructura; no muestra registros ni secretos.

Una línea indica una clave foránea. La cardinalidad se calcula a partir de las restricciones e índices únicos de la tabla hija. Un vínculo obligatorio exige padre para cada hijo; no exige que todo padre tenga hijos.

Las relaciones N:M se implementan mediante tablas como organization_memberships, payment_allocations y contract_items.

La existencia de una tabla no significa que cada pantalla ya esté conectada a ella.
